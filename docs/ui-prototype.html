设计语言「朱批」——三个记忆点
① 单词用衬线大字（Iowan / Georgia / Noto Serif），UI 其余用无衬线。市面上背单词 App 全是无衬线圆卡片，单词只是内容；这里单词是主角，读起来像一页印刷品。
② 朱砂红 #C0452F 只出现在极少数位置：主按钮、选中标记、进度、「重来」档。旧书批注的那支笔。大面积留给纸白与墨黑。
③ 评分按钮顶部的横条 = 间隔长度。重来条最短、简单条最长，不用读数字就知道四个档位的量级差异——把抽象档位翻译成可见的长度。
细节：分割线统一 hairline 1px 且极淡；小标签 uppercase + 1.1px 字距；所有数字 tabular-nums 对齐；圆角收到 6–10dp（印刷感，不用 16dp 气泡）；标记一律 5–7px 方块而非圆点。
