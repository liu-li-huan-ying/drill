设计语言「朱批」——三个记忆点
① 单词用衬线大字（Iowan / Georgia / Noto Serif），UI 其余用无衬线；页面标题的中文也走衬线（宋体）。市面上背单词 App 全是无衬线圆卡片，单词只是内容；这里单词是主角，读起来像一页印刷品。
② 朱砂红 #C0452F 只出现在极少数位置：主按钮、选中标记、进度、「重来」档、词性标签。旧书批注的那支笔。大面积留给纸白与墨黑。
③ 评分按钮顶部的横条 = 下次间隔。重来条最短、简单条最长，不用读数字就知道量级差异——把抽象档位翻译成可见的长度。
v2.1 改动：首页进度环改为 20 格刻度环（一格 = 一个新词，完成填朱砂），比连续圆环更可数、更有手感；词库每行加词数条；柱状图加基线；开关补 track。
「词汇量测试」重构为「熟词校准」——它本质是冷启动校准而非学习功能，拆成两处：首次点「开始学习」时若未校准，先走 20 题（30 秒，可跳过）再接今日新词；之后作为常驻工具可反复使用。日常「这词我早就会了」由任意位置的「标为已掌握」解决，不靠集中测试。
