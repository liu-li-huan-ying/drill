# 设计系统 v1 · 朱批

> 交互原型：[`docs/ui-prototype.html`](ui-prototype.html)（浏览器打开，右上角切「纸 / 墨」）
> 本文件是原型的规格说明书：原型负责看，本文件负责约束实现。M2 起所有 UI 代码以此为准。

## 0. 设计语言的由来

第一版原型做出来「没有辨识度」——靛蓝主色 + 16dp 圆角卡片 + 四色块评分按钮，本质是 Material 默认件的排列组合，换任何一家背单词 App 的 logo 都说得通。

问题在于**没有回答「这个 App 看起来应该像什么」**。市面上的共同形态是：无衬线字体、圆润卡片、插画或 emoji、高饱和渐变主色、游戏化打卡。单词在这些界面里只是**内容**，不是**主角**。

**「朱批」的回答是：让单词本身成为设计。**

三个记忆点：

1. **单词用衬线大字**（Iowan Old Style / Georgia / Noto Serif），UI 其余部分用无衬线。这是中英混排的经典做法，也是背单词 App 几乎没人做的。读起来像一页印刷品，而不是一张卡片。
2. **朱砂红 `#C0452F`** 作为唯一的强调色，只出现在极少数位置：主按钮、选中标记、进度条、「重来」档、词性标签。大面积留给纸白与墨黑。取自旧书上那支批注的笔。
3. **评分按钮顶部的横条长度 = 下次间隔**。重来 14dp、困难 26dp、良好 42dp、简单 66dp。不用读数字就能看出四个档位的量级差异——把抽象的「困难/良好」翻译成可见的长度。

## 2. 配色令牌

亮暗两套由**同一组令牌名**驱动，运行时跟随系统 `appearance`。

| 令牌 | 用途 | 亮（纸） | 暗（墨） |
|---|---|---|---|
| `--bg` | 页面底色 | `#FBF9F5` | `#141311` |
| `--sf` | 卡片面 | `#FFFFFF` | `#1C1A17` |
| `--pg` | 机身/分组底 | `#F2EFE8` | `#0E0D0C` |
| `--tx1` | 主文本（墨） | `#1B1917` | `#EDE8DE` |
| `--tx2` | 次要文本 | `#6E6862` | `#A79F94` |
| `--tx3` | 弱化文本 | `#A89F94` | `#6F685E` |
| `--bd` | hairline | `#E7E2D8` | `#2C2925` |
| `--bd2` | 描边 | `#D8D2C6` | `#3A362F` |
| `--ac` | 朱砂 | `#C0452F` | `#E0705A` |
| `--acsf` | 朱砂浅底 | `#F7EBE6` | `#2E211C` |

底色不是纯白而是**暖调纸白**（`#FBF9F5`），暗色不是纯黑而是**暖调墨黑**（`#141311`）——纯白/纯黑会让衬线字显得廉价。

### 四档评分

| 档位 | 亮·底 / 字 | 暗·底 / 字 | 条长 |
|---|---|---|---|
| 重来 Again | `#F7EBE6` / `#C0452F` | `#2E211C` / `#E0705A` | 14dp |
| 困难 Hard | `#F2EEE5` / `#1B1917` | `#262320` / `#EDE8DE` | 26dp |
| 良好 Good | `#F5F3EC` / `#1B1917` | `#242720` / `#EDE8DE` | 42dp |
| 简单 Easy | `#EAEDE4` / `#1B1917` | `#212420` / `#EDE8DE` | 66dp |

只有「重来」用朱砂，其余三档靠底的冷暖微差 + 条长递进区分。不做四色高饱和色块。

## 3. 字体

两套字族分工明确：

- **衬线 `--serif`**：`Iowan Old Style, Palatino Linotype, Georgia, Times New Roman, Noto Serif, Source Serif 4, serif`
  用于：单词、页面标题、例句（斜体）、释义编号、统计数字
- **无衬线**：系统默认
  用于：释义中文、列表、按钮、标签、设置项
- **等宽**：`SF Mono, Consolas, monospace`
  用于：音标（配合 +0.8px 字距，词典感）

| 级别 | 字号 | 用途 |
|---|---|---|
| 42 sp 衬线 | 复习/新词卡单词 |
| 36 sp 衬线 | 测试词 |
| 33 sp 衬线 | 详情页单词 |
| 27 sp 衬线 | 卡背面单词、统计数字 |
| 25 sp 衬线 | 页面标题 |
| 16.5 sp 无衬线 | 中文释义 |
| 14 sp 衬线斜体 | 英文例句 |
| 13 sp 等宽 | 音标 |
| 10.5 sp 无衬线 | 小标签，uppercase + 1.1px 字距 |

## 4. 细节纪律

这几条是「有设计感」和「没设计感」的分界线，实现时必须遵守：

- **分割线一律 hairline**——1px，颜色用 `--bd` 而不是 `--bd2`。粗线是廉价的头号来源。
- **所有数字 `font-variant-numeric: tabular-nums`**——包括进度、词数、间隔、统计。数字跳动会毁掉排版。
- **小标签 uppercase + 字距**——10.5sp + 1.1px 字距 + 中文字间加半角空格（「释 义」）。这是印刷品的做法。
- **标记一律方块不用圆点**——5–7px 的朱砂小方块（`.mk`），用于 tab 选中态、词库选中态、开关开启态、词根条目。圆点太软，方块有批注感。
- **图标 stroke-width 1.5**，不填充。tab 图标 21×21。
- **例句用衬线斜体**，关键词不用加粗，用 `--tx1` 提亮或朱砂下划线。
- **不做渐变、不做长阴影**。卡片阴影极轻或只用 1px 描边。

## 5. 关键交互决策

### 5.1 新词与复习走两条不同的路（v2 新增）

v1 原型只有一张翻转卡 + 四档评分，这是个**语义缺陷**：一个从没见过的词，让用户在「重来 / 困难 / 良好 / 简单」里选，FSRS 的首次评分语义是崩的——Again 表示「忘了」，可你根本没记过。

拆成两张卡：

| | 新词卡 | 复习卡 |
|---|---|---|
| 顶部标签 | 首 次 接 触 | 复习 12 / 47 |
| 底部按钮 | 不认识 / 认识（**认知判断**） | 重来 / 困难 / 良好 / 简单（**记忆评分**） |
| FSRS | 首次评分为 Good 入队，具体 due 由首评决定 | 正常四档调度 |

### 5.2 卡正面只有「单词 + 音标」

不显示释义、不显示例句。正面信息越多，用户越容易在回忆之前被动接收，回忆强度下降。音标是发音线索不算答案，保留。

### 5.3 评分按钮显示下次间隔（长度 + 数字双编码）

沿用 Anki 已验证的做法，并加一层视觉编码：条长表达量级，数字表达精确值。

### 5.4 「想不起来按重来」

FSRS 里 Hard 的语义是「想起来了但吃力」，Again 才是「没想起来」。新手普遍误用 Hard，导致调度器把没记住的词排到远期。评分区上方常驻提示行。

### 5.5 详情页纵向单列，不做内分页

不背单词用了「释义/例句/助记」分页 tab，观感整洁但查一个词要点三次。本设计单列滚动，一屏看全。排版按词典条目：编号 + 词性 small-caps + 释义。

### 5.6 不做游戏化

无连续打卡徽章、无排行榜、无鼓励弹窗、无成就。统计页只给数据。

## 7. 无障碍

- 正文对比度 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1
- 不靠颜色单独传达状态：四档评分同时有颜色 + 条长 + 文字
- 支持系统字号缩放，卡片内容区可滚动
