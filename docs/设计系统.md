# 设计系统 v1

> 交互原型：[`docs/ui-prototype.html`](ui-prototype.html)（浏览器打开，右上角可切亮/暗）
> 本文件是原型的「规格说明书」：原型负责看，本文件负责约束实现。M2 起所有 UI 代码以此为准。

## 1. 画布与单位

| 项 | 值 | 说明 |
|---|---|---|
| 基准机型 | 360 × 752 dp | 安卓主流中端机逻辑分辨率（Pixel 系列约 412dp，本设计向下兼容到 320dp） |
| 单位 | dp / sp | RN 中 `width:360` 即 360dp；`fontSize:16` 即 16sp。原型里 1px = 1dp |
| 状态栏 | 44dp | 系统状态栏 |
| 手势条 | 22dp | 安卓导航手势条，底部 tab bar 在其上方 |
| 顶部工具栏 | 48dp | 与触摸目标下限一致 |
| 左右边距 | 20dp | 内容区安全边距 |
| 最小触摸目标 | 48 × 48 dp | 全部可点元素不低于此值 |
| 圆角 | 16 / 12 / 8 dp | 卡片 / 按钮 / 小控件 |

**为什么先定画布**：之前一版原型把手机框缩到 ~150px 宽，字号仍是绝对值，导致 32sp 的单词占屏宽 19%（真机应为 ~8%），视觉失真。原型必须与真机 1:1，否则「好不好看」的判断不可信。

### 四档评分语义色

FSRS 四档按钮必须有语义色，否则用户每次都要读文字才知道哪个是哪个：

| 档位 | 含义 | 亮·底 / 字 | 暗·底 / 字 |
|---|---|---|---|
| Again | 重来（忘了） | `#FCEDEC` / `#C04A4A` | `#3A2226` / `#E79A9A` |
| Hard | 困难（想起来了但吃力） | `#FDF3E7` / `#B26A1A` | `#3A2E20` / `#E0B273` |
| Good | 良好 | `#EDF5EC` / `#4A7C46` | `#243526` / `#9CCB96` |
| Easy | 简单 | `#ECF3FA` / `#3D6FA8` | `#1F2C3A` / `#93B8E0` |

刻意**不用**红=失败的强警示配色，改为低饱和莫兰迪色系（见下）。

## 4. 风格定调：温和精致派

- 低饱和、中低对比的品牌色（靛蓝 `#5B67CA`），不用高饱和渐变
- 大量留白，圆角 12-16dp，克制的 1px 描边，弱化阴影
- 动效轻量：卡片翻转 ~220ms，按钮反馈即时
- **不做**游戏化：无连续打卡天数徽章、无排行榜、无鼓励弹窗。学习本身是反馈

## 5. 关键交互决策（含依据）

### 5.1 复习卡正面只给「单词 + 音标」

不显示释义、不显示例句。理由：正面信息越多，用户越容易在「看答案」之前就被动接收，回忆强度下降。音标是发音线索不算答案，保留。

### 5.2 四个评分按钮上显示「下次间隔」

沿用 Anki 已验证的做法——每个按钮直接标出选它之后这张卡下次何时再来（`<10分钟` / `1天` / `4天` / `12天`）。这把抽象的「困难/良好」翻译成具体后果，是用户最快学会正确使用四档的方式。

### 5.3 忘了要按「重来」，不是「困难」

FSRS 里 Hard 的语义是「想起来了，但很吃力」，Again 才是「没想起来」。绝大多数新手会误用 Hard 表示忘了，导致调度器把没记住的词排到远期，间隔被系统性拉长。原型在评分区上方常驻一行提示：「想不起来按「重来」，别按「困难」」。

### 5.4 正面提供「不认识」快捷出口

参考扇贝的「更改为不认识」——首次接触的生词不该假装回忆，直接进入学习态。原型在正面提供 `不认识 → 直接看答案` 的通道。

### 5.5 底部 4 tab：学习 / 词库 / 统计 / 设置

不采用「单词详情页内分页 tab（释义/例句/助记）」。参考对象里不背单词用了分页，观感更整洁但查一个词要点三次；本设计改为详情页单列纵向滚动，一屏看到全部信息。

## 6. 屏幕清单（原型覆盖 8 屏）

| # | 屏幕 | 要点 |
|---|---|---|
| 1 | 今日学习 | 今日待办：新学 20 / 复习 200，主按钮「开始学习」，显示剩余量与预计时长 |
| 2 | 复习·正面 | 单词 32sp + 音标，发音按钮，底部「不认识」出口 |
| 3 | 复习·背面 | 释义 + 例句，底部四档评分带间隔，Again 提示行 |
| 4 | 词汇量测试 | 认识 / 不认识 二选，分层抽样，进度条 |
| 5 | 词库 | 标签 chips，多选，导入自定义词表入口 |
| 6 | 统计 | 7 日柱状图、掌握度分布、留存率 |
| 7 | 单词详情 | 释义 / 例句 / 词根词缀 / 手写助记 纵向单列 |
| 8 | 设置 | 每日新词 20、复习上限 200、目标留存率 90%、每日分界 04:00 |

## 7. 无障碍与对比度

- 正文对比度 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1
- 不靠颜色单独传达状态：四档评分同时有色 + 文字
- 支持系统字号缩放，卡片内容区可滚动，超限不裁切
